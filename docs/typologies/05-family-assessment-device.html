Report 05 / household structure

McMaster家族機能モデルとFAD

会話の良し悪しだけでなく、問題解決、役割、感情、関与、行動統制という生活の仕組みを多次元で見る。夫婦の固定タイプではなく、領域別のプロフィールとして使う。

確認できたこと／できないこと

2 支持あり
FADは家族機能の多次元自己報告尺度として信頼性・妥当性の根拠がある。 原検証では再検査信頼性、社会的望ましさとの低い相関、他尺度との中程度の相関、臨床家が健康／不健康と評定した家族の識別が報告された。
2 支持あり
全般機能12項目版は各国で継続検証されている。 ただし因子構造は版・標本によって一様ではなく、短縮だけで全領域を説明することはできない。
3 予備的
日本語版の信頼性・妥当性研究は1997年に存在するが、公開書誌から標本・数値を確認できない。 日本で製品利用する前に原文、採点、権利、現在集団での測定特性を再確認する必要がある。
4 不採用
FAD得点を夫婦タイプや治療効果へ読み替えること。 FADは状態のプロフィールであり、特定の介入が効くことを単独で証明しない。

FACES IIIではなくFADを残した理由

旧集計はFACES IIIの「凝集性×適応性による16類型」を実証済みとしていた。しかし日本の190家族による検証では、良好な家族が円環の中央に集まる仮説は支持されず、適応性下位尺度の因子構造も不安定だった。FADは極端値を型に割り当てず、問題解決・役割・感情などを線形の領域別得点として見るため、実務上の誤読が少ない。

支援での使い方

  1. 双方の視点を別に取る。 家族全体を一人の回答で代表させず、差を平均で消さない。
  2. 低い領域を行動へ戻す。 「役割機能が低い」ではなく、誰が何をいつ担い、抜けたときどう代替するかまで具体化する。
  3. 一領域だけ変更する。 情報伝達の問題と担当不履行を混ぜず、まず観測可能な一つを選ぶ。
  4. 全般満足度と別に追う。 満足度がすぐ変わらなくても、担当実施や威圧停止など生活条件の変化を記録する。

尺度項目の転載・自動採点は権利確認後に行う。 独自質問を使う場合は「FAD」と表示せず、7軸を参考にした生活構造チェックとして区別する。
