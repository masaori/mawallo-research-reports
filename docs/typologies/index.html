先に結論

採用順は「全体地図 → 共同対処 → 会話循環 → 個人の反応傾向 → 生活構造」。 Gottmanの葛藤類型は説明補助に留める。どの枠組みも、単独で夫婦の将来を診断する道具にはしない。

6つの独立レポート

旧版で収集した65件をすべて確認する場合は、4段階基準を適用し直した全件集計レポートを参照。実際の支援設計へ進める候補は、以下の6件に絞った。

REPORT 01

脆弱性―ストレス―適応モデル

「性格のせい」にせず、変えにくい傾向、外部負荷、変えられる相互作用を分ける。

REPORT 02

二者間コーピング

問題を二人の共同課題として扱えているか、本人・相手・共同の3視点で見る。

REPORT 03

要求―撤退パターン

「話す人」と「逃げる人」の人格ではなく、相互に増幅する会話の循環を捉える。

REPORT 04

成人愛着の不安・回避

安心確認を求める強さと、近接を避ける強さを連続量で扱い、伝え方を調整する。

REPORT 05

McMaster家族機能モデル

会話だけでなく、問題解決、役割、感情、行動統制という生活の仕組みを見る。

REPORT 06

Gottmanの葛藤スタイル

回避・妥当化・激動という異なる安定形を認めつつ、敵意と離脱を別に扱う。

4段階は「主張」につける

1 再現済み
複数の独立研究・メタ分析・統合分析で再現。 関連研究なら「関連がある」までであり、「変えれば改善する」まで自動的に昇格しない。
2 支持あり
単一の強い研究または複数の限定的研究。 アセスメント仮説として使い、前後の観測で確かめる。
3 予備的
小標本、文化移植前、横断研究、専門訓練依存。 自動判定や利用者への断定表示には使わない。
4 不採用
反証・採点非公開・再現不能・安全上不適切。 診断、推薦、効果説明から除外する。

共通の停止条件

暴力、威嚇、監視、経済的支配、性的強要、孤立化が疑われる場合、二人の「コミュニケーション問題」として扱わない。 被害側へ対称な責任を負わせず、安全確認と専門支援への接続を優先する。WHOは支援で本人と子どもの安全を最優先し、危害を増やさないことを求めている。
