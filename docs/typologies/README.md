# 夫婦支援に使える理論・尺度の再調査

更新日: 2026-08-11

旧 `report.md` は削除した。旧 `report.html` も一度削除し、65件を残したまま主張単位の4段階基準を適用した [`report.html`](./report.html) として作り直した。旧版は尺度の信頼性、関連の再現、将来予測、介入効果を同じ「エビデンス」として数え、反証された類型と検証済みの連続尺度も同列に見せていたため、その集計値は引き継いでいない。

この再調査は「夫婦を何タイプかに固定分類する」ことを目的にしない。夫婦支援で次の観測・働きかけを決めるために、再現可能な枠組みを6件だけ選んだ。

## 4段階のエビデンス

評価は理論全体ではなく、個々の主張につける。同じ理論でも「関連がある」はレベル1、「介入すれば改善する」はレベル3になりうる。

| レベル | 名称 | 判定条件 | 許される使い方 |
|---|---|---|---|
| **1** | 再現済み | 主張に適した複数の独立研究、メタ分析、または複数データセットの統合分析で再現 | 既知の傾向として設計判断に使う。ただし関連研究だけなら因果は主張しない |
| **2** | 支持あり | 単一の強い研究、複数の限定的研究、妥当性検証済み尺度 | アセスメント仮説や試行候補に使い、結果を追跡する |
| **3** | 予備的 | 小標本、横断研究のみ、文化適用が未確認、専門訓練が必要、独立再現が不足 | 研究・プロトタイプに限定し、利用者を型で断定しない |
| **4** | 不採用 | 中核主張が反証、採点法が非公開、再現不能、または安全に適用できない | 診断・推薦・説明に使わない |

## 選んだ6件

1. **脆弱性―ストレス―適応モデル（VSA）**: 問題を「個人の傾向」「外部ストレス」「二人の適応行動」に分解する全体地図。
2. **二者間コーピング（DCI）**: ストレスの伝達、支援、共同対処、否定的対処を二人の視点で測る。
3. **要求―撤退パターン（CPQ）**: 一方が解決を迫り、他方が黙る・避ける循環を扱う。
4. **成人愛着の不安・回避（ECR-RS）**: 4タイプではなく2つの連続量として、支援の受け取り方を理解する。
5. **McMaster家族機能モデル（FAD）**: 問題解決、役割、感情、行動統制を含む生活構造の多次元プロフィール。
6. **Gottmanの葛藤スタイル**: 葛藤回避・妥当化・激動を一律に悪としない観察枠。ただし離婚予測器にはしない。

ブラウザ用の入口は [`index.html`](./index.html)。各レポートは、確認できた主張、確認できない主張、実務での使い方、停止条件、出典を分離して記載した。

レベル1〜3の57件を「人間をどう分類するか」という観点で外観する資料は [`classification-map.html`](./classification-map.html)。分類単位、分類内容、型の生成法、判定入力、出力形式の5軸について、割合グラフ、表全体を閉じた分類表、エビデンスレベル別の個別説明一覧表を収録した。

## 再集計で外したもの

- MBTI、エニアグラム、5つの愛の言語、FFS、Satirの5スタンスなど、型の境界・採点・中核主張を支持できないもの。
- ENRICHの5類型など、同じデータでもクラスタ数の選択で型数が変わり、商用尺度への依存が強いもの。
- FACES IIIの16類型。日本の検証研究（N=190）は円環仮説を支持せず、適応性下位尺度の因子構造も不安定だった。家族機能を見る用途はMcMaster FADへ置き換えた。
- Big Fiveなど、関連はあっても「似た性格同士ならうまくいく」という相性型へ丸める根拠がないもの。

## 関連する体験談資料との接続

[`夫婦仲の悪化と修復_体験談/analysis.md`](../夫婦仲の悪化と修復_体験談/analysis.md) は、160件すべてが片側の語りで、改善の定義も出所も揃わないため介入効果の順位づけには使えない。一方、外部ストレス、要求―撤退、生活上の役割、支援の受け取り方という観測項目を作るための語彙としては使える。成果は「関係が良くなった」という一方の自己申告だけでなく、負担配分、会話の再開、威圧行動の停止、支援利用など観測可能な変化で追う。

暴力、威嚇、監視、経済的支配、性的強要、孤立化がある場合は、相互作用の「型」として二人に対称な責任を負わせない。安全確保と専門支援への接続を先にする。
