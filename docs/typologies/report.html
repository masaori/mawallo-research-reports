この集計から分かること

65件のうち、固定タイプのまま支援判断へ使えるものは確認できなかった。 レベル1・2でも、支持されるのは多くの場合「連続尺度の関連」「反復された集団傾向」「標準化された観察」であり、個人を型へ固定することや介入効果まで保証しない。

レベル件数集計上の意味実務上の扱い

判定方法

  1. 理論名ではなく主張を評価した。 例として成人愛着では「不安・回避の連続量」は支持されても、「4タイプへ分ければ有効」は同じ強さではない。
  2. 測れること、関連すること、将来を予測すること、介入で変わることを分離した。 尺度の信頼性だけでは介入効果の根拠にならない。
  3. 高品質な調査データと診断道具を区別した。 全国調査は集団傾向には有用だが、個人の型判定には使えない。
  4. 各行は実務上もっとも重要な一つの主張で代表させた。 同じ項目により弱い副次主張がある場合は、判定理由に明記した。

件数は65件を重複なく一度ずつ数えたもの。レベルは理論の知名度や標本数だけで決めていない。
