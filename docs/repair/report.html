試したこと

記録上の結末
良好（共同で新居建築まで到達）

夫婦の型

  • 夫：嫌なことは即「嫌だ」と言い、怒りを感情的に表現する。
  • 妻：揉め事を避けるため気持ちを隠す。毒親の下で育ち、不当な感情にも耐える癖がある。

悪化の経緯

夫が「言いたいことがあるなら言え」と促しても、妻は「言い返したらもっと大変になる」と本音を隠す。妻の内心には「怒るときの言葉遣いが嫌だ」「傷つける言葉を選ぶのはやめてほしい」という不満が溜まっていた。最終的に一週間口をきかない大喧嘩に発展。

やったこと（8年かけた対話の型）

1. 怒りそうになったら一旦止まり、物理的に距離を置く 2. 落ち着いてから相手の話を全部聞く 3. 「私はこう思って」と自分の気持ちを説明する 4. 「なぜそう思ったんだろうね？」と一緒に考える 5. 「次はこうしようか」と次の行動を決める

加えて、互いの過去の傷つきを丁寧に拾い、「本当はこう感じていたけれど隠していた」という気持ちに向き合った。

結果

8年目から深い対話が可能に。「どちらかが我慢する」から「二人でつくりあげる」へ意識が転換し、新居建築という大きな共同プロジェクトを完遂した。

筆者自身の留保

「この方法が万人に確実に合うとは保証できない」。夫に改善意欲があったから成立したと明言している。
